# Shopping List

Jednoduchá nákupní aplikace v češtině.

## Funkce

- kategorie s ikonami
- předpřipravené položky
- vlastní kategorie a položky
- množství položek
- označení koupených položek
- vyhledávání
- světlý a tmavý režim
- automatické ukládání v zařízení

## Publikování

Aplikace je připravena jako statická stránka pro GitHub Pages. Hlavním souborem je `index.html`.
